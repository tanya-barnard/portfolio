This site is part of the portfolio.

A custom professional portfolio designed to separate job-seeking materials from a consulting brand while demonstrating practical information architecture, HTML/CSS implementation, responsive design and AI-assisted development.

GitHub PagesFree static-site hosting

The brief

Create a professional proof-of-work portfolio for job applications without directing employers to a separate consulting business website. The portfolio needed to feel credible, modern and evidence-led rather than repeating a CV.

Design decisions

  • Case studies lead with problems and outcomes
  • About content focuses on how I work, not employment history
  • References use real third-party feedback
  • Skills are grouped by operating capability rather than a long tool list
  • Static HTML/CSS keeps the site lightweight and portable
Build approach

Small stack. Clear structure.

The site deliberately avoids a heavy website builder so the implementation remains transparent and easy to maintain.

Content architectureDefined the portfolio hierarchy: About, proof of capability, Work, References and Certifications.
Front-endCustom HTML and CSS with responsive layouts, hover effects and a CSS marquee.
Development workflowUsed AI-assisted development to accelerate code generation and iteration while directing the content, structure and design choices.
DeploymentPublished from a GitHub repository using GitHub Pages.
